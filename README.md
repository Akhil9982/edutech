**EduTech** is a responsive education website clone designed to showcase modern frontend development skills. It serves as a static landing page for an online learning platform, featuring a clean layout and professional UI components.

---

## 🌟 Live Demo

> https://akhil9982.github.io/edutech/

---

## 🚀 Features

- **Responsive Design**: Adapts seamlessy to desktops, tablets, and mobile devices.
- **Modern UI/UX**: Clean aesthetic suitable for educational institutions or e-learning platforms.
- **Semantic HTML5**: Well-structured code for better accessibility and SEO.
- **Pure CSS Styling**: Custom styling located in `css/` without reliance on heavy frameworks.
- **Asset Management**: Organized image assets in the `assets/images` directory.

## 🛠️ Technologies Used

- **HTML5**: Structural framework of the webpage (`index.html`).
- **CSS3**: Custom styling and responsive media queries (`css/`).
- **Git**: Version control.

```bash
edutech/

💻 Getting Started

This is a static website, so no complex installation or backend server is required.

Prerequisites

A modern web browser (Chrome, Firefox, Safari, Edge).

A code editor (VS Code, Sublime Text) if you wish to modify the code.

Installation

Clone the repository:

Bash

git clone [https://github.com/Akhil9982/edutech.git](https://github.com/Akhil9982/edutech.git)

Navigate to the project directory:

Bash

cd edutech

Launch the Site:

Locate the index.html file in the project folder.

Double-click it to open it in your default web browser.
